# 补件复检

1. 调用 get_case_context，确认当前修订号和已有检查，不沿用旧事实。
2. 调用 run_checks，对当前快照重新检查。首版保守全量复检，避免漏掉新增材料解决的缺件。
3. 读取变化涉及的材料；语义检查保留直接引文。无法读取时保留 unknown。
4. 对比 previous_findings 和本次结果，解释已解决、仍未解决与新增的问题。
5. 输出检查范围、变化、证据和下一步。已过期人工确认需要重新进行。

补件不能自动启用新要求、代签、修改原件或提交申请。
