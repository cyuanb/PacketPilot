# 任务、协作与数据管理

## 持续准备材料

“计划与期限”保存行动任务、待答问题、待审阅建议、工作草稿、外部截止和资料到期。任务状态与材料检查结论分开：完成任务不会把未通过的规则变成通过。建议可以从当前问题生成，用户明确采纳后再修改相应材料或背景。

期限按输入设备时区转换为带时区时间保存。提醒按同一任务的当前状态计算，不重复创建通知；完成/取消后不再提醒。账号与数据入口汇总站内提醒，事项可导出 ICS 日历。提醒在访问 Web 时显示，不承诺浏览器关闭时推送或自动发送邮件。

“材料加工”可合并 PDF/图片、选择 PDF 页码与顺序、旋转、调整图片尺寸/JPEG 质量。成果另存为独立资料并记录来源和加工参数；原件不变。输出需人工核对版式、页序与签署有效性，电子签名不会因此被重新认证。输出最多 100 页，并受单文件 20 MiB 限制。

## 分享与收集

所有者在事项中明确创建三种授权之一：只读材料、材料复核或限定收集。分享固定材料版本，文件替换后不自动授权新版本；协助者不能通过分享获得整个资料中心、通知、聊天或事项管理权限。

邀请码只展示一次，由所有者自行安全转交。接受邀请时可创建账号，已有账号须验证密码。登录后在“协作、账号与数据”访问授权。邀请默认 7 天，可撤销，服务器每次请求重新核对授权；撤销不能收回用户此前已经下载的副本。

收集者只能上传本收集任务的文件（最多 10 份），无法读取已有资料。所有者接收后文件才进入事项解析；退回须填写原因。复核者可按页和原文片段评论、认可或退回；意见绑定解析版本，版本变化后标为历史意见，不自动改变机器预检结果。

## 账号恢复

登录后可核对当前会话和其他会话并分别撤销。确认密码后生成离线恢复码，仅显示一次；新码替代旧码。恢复时重置密码并撤销全部旧会话，恢复码只能使用一次。不要把恢复码放进公共仓库或分享给协助者。

## 数据保管

数据备份包含当前所有者空间的事项、资料、原件、解析历史、冻结包和任务。备份不包含密码、会话、恢复码、对外授权与邀请码。备份含敏感材料且未自行加密，请放入可信的加密存储或受保护目录。

恢复先校验清单和哈希，再导入为独立副本；不会覆盖已有事项，也不会自动重放备份中的运行中任务。副本分配新的内部标识，冻结包仍保持原来字节及清单，授权需重新建立。便携备份上限 300 MiB。完整服务迁移仍应在停服后保留 PostgreSQL 数据备份与配置的数据目录，配套恢复到隔离环境验证后再切换服务。

资料须先归档才能永久清除。仍被事项历史或冻结包引用时清除会被阻止。无引用的原件会随资料清除；已下载文件、既有备份、浏览器缓存和外部副本需另行处理。

## 运行与能力边界

诊断页只显示任务状态、尝试次数和错误摘要；失败/取消任务可按当前输入重试。每所有者最多 10 个待处理任务，模型运行有 8 轮工具步骤及 180 秒总时间预算（单次网络调用另有超时），单文件、解析页数与模型输入也有限制。

模型不可用时可使用基础规则预检；语义项保持未知。本机 OCR 未准备时可保留原件并人工校订。当前支持基线为 Windows 原生后端和桌面浏览器。该版本为免费功能预览，真实用户试用及具体行业规则验收需另行完成；不宣称官方审核、自动提交或通用真实性验证。

升级前停止服务并备份；安装锁定依赖、执行 `python -m alembic -c backend/alembic.ini upgrade head`、构建前端，再通过 `scripts/start.ps1` 启动。包含新增业务数据的迁移不允许无保护降级；需要回退时恢复配对备份，并在副本中验证。

申请本身的截止日期也会自动进入站内提醒与 ICS 日历，修改日期后同步更新，不必重复创建任务。只知道日期时导出全天日期事件，不假定具体截止时刻。解析取消或从备份恢复的未完成解析会显示待核对，可重新解析；重试会使旧检查失效，并阻止重复排队。
