# 使用说明

## 工作空间与主体档案

首次使用时，账号拥有自己的工作空间；原有事项会保留原所有者并归入该空间。可在「主体档案」页面修改工作空间名称。

登录账号是操作者。为申请人、推荐人、组织和经办人分别创建主体档案，再在事项页面点击「关联主体与角色」选择对应档案。同名主体不会合并，选择时可通过区分备注和档案标识核对。组织可以作为申请主体；推荐人、联系人和经办人使用个人档案。

主体档案支持编辑、搜索、查看关联事项和归档。归档保留原有角色关联，但不能新增关联；恢复档案后可继续选择。修改关联中的主体或角色会使相关事项的既有结果需要复核；已经生成的任务快照保持原样。

档案字段不会自动成为申请背景中的已确认事实。角色关联用于整理身份与归属，当前检查尚不自动按不同主体分别进行字段比较。当前工作空间由所有者本人管理，不提供注册或邀请入口。

## 建立事项

填写名称、机构和可确定的截止日期。通过粘贴文本或上传通知建立依据，提取后审阅要求并启用。

## 上传和核对材料

材料库接受支持的文件类型。上传、替换和人工校订产生可追溯版本。文件已上传不等于其内容已经读取。

预检后查看每项理由、引用和下一步。无法读取的图片或扫描件需要可读副本或校订文本。签名、盖章等项目由用户查看原件后记录人工确认。

## 补件与导出

修改材料、背景或要求后重新预检。只有符合当前版本检查契约的结果才能导出。导出的是检查清单，不是向外部机构自动提交。

## 数据管理

归档保留事项记录。删除材料会影响依赖它的历史检查；删除事项会清除相关记录。备份中的副本由部署者自行管理。
