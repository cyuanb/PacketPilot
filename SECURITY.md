# Security

V0.1 is a local single-owner workspace, not a publicly audited multi-tenant service.

Credentials belong in ignored .env or environment variables. Model servers receive necessary excerpts. Original downloads require an authenticated session.

Parser subprocesses have time/output limits, not a hardened security sandbox.

Use GitHub private vulnerability reporting if enabled, or privately contact the maintainer through their profile. Never post private documents or live credentials in public issues.
